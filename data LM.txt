# Legends Marketing — Website Architecture & Feature Blueprint

## Brand Positioning

**Legends Marketing**  
**Tagline:** Turning Properties into Profitable Opportunities

The website should be positioned as a **modern real estate investment platform**, not simply a company profile website.

### Primary Goals
- Build a premium and trustworthy real estate brand.
- Generate qualified property-investment leads.
- Showcase multiple projects in a scalable structure.
- Serve local investors and overseas Pakistanis.
- Improve organic Google visibility through useful, project-specific content.
- Convert visitors into WhatsApp conversations, calls, consultations and bookings.

# 2. Dynamic Project System

Build the website with a **CMS-based dynamic project system**.

Admin workflow:

> Add New Project ? Enter Details ? Upload Images ? Add Payment Plan ? Add Documents ? Publish

This allows future projects to be added without redesigning the website.

### Every Project Should Have

- Project Overview
- Location
- Master Plan
- Blocks / Sectors
- Development Updates
- Payment Plans
- Current Price / Availability
- Investment Highlights
- Amenities
- Gallery
- FAQs
- Legal / Approval Information where applicable
- Advisor Details
- WhatsApp CTA
- Booking / Enquiry Form
