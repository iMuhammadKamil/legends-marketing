# LEGENDS MARKETING

Professional real-estate investment website platform.

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Architecture:** Static + Dynamic Hybrid (SSG + ISR)

## Getting Started

```bash
npm install
npm run dev
```

## Structure

- `src/app/` - All routes/pages (file-based routing)
- `src/components/` - Reusable UI components
- `src/data/` - Content data (projects, navigation, services)
- `src/types/` - TypeScript contracts
- `src/lib/` - Utilities, constants, SEO helpers
